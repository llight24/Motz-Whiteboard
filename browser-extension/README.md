# MOTZ 白板收集器

这是 MOTZ 白板的 Chrome/Edge 浏览器插件。它会在拖动网页图片时显示一个悬浮收集框：

- 拖到“素材库”：下载图片并保存到 MOTZ 素材库。
- 拖到“当前白板”：下载图片并发送到 MOTZ 当前白板。

## 安装方式

1. 先打开新版 MOTZ 白板桌面端。
2. 打开 Chrome 或 Edge。
3. 进入扩展管理页：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
4. 打开“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择这个文件夹：`browser-extension`

## 使用方式

1. 在网页里拖动一张图片。
2. 页面中央会出现 MOTZ 收集框。
3. 松手到“素材库”或“当前白板”。

## 注意

- 桌面端需要保持打开，因为插件会通过 `http://127.0.0.1:39875` 把图片链接交给 MOTZ。
- 有些网站会限制图片下载。如果网站阻止跨站请求，插件会提示失败。
- 当前版本主要支持网页图片，视频后续可以继续扩展。
